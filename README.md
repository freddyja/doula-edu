# Doula

A calm, local-first web app for prenatal and postpartum preparation: a daily prep path, birth education, and gentle movement.

This is general wellness support. It is not medical advice, not a diagnosis, and not a treatment plan. Follow your care provider.

Hosted only on GitHub Pages, not Vercel:

https://freddyja.github.io/doula-edu/

## Three lanes

Prep, Learn, and Move share the stage you choose and the same on-device progress.

### Prep

An optional 8-week path. One bite-sized card per calendar day after you tap start on Today. Each week uses five pillars, in this order:

1. Mindset
2. Movement
3. Nutrition — a wellness tip, not a meal plan or medical nutrition advice
4. Partner support
5. Birth education
6. Movement again
7. Mindset again

Day 1 is the day you start. If you miss a day, the calendar still moves, and the missed card stays on the path so you can mark it later. Future cards wait. A streak counts consecutive marked days through today, or through yesterday if today is still open. After the 8 weeks, there is no new card. Lessons and movement stay available.

The path is written with pregnancy in mind. If you have already given birth, use the cards that still help.

### Learn

Stage-based lessons: what this part of pregnancy or postpartum is often like, how labor is commonly described, comfort and breath, mental prep, partner support, a packing list, questions to discuss for a birth plan, and newborn basics. The birth-plan page is a list of questions for your care provider, not a clinical plan.

### Move

Short practices, plus longer follow-along sessions (about 15–30 minutes of written steps, no video) grouped by pelvic level:

- **Inlet** — top of the pelvis
- **Mid** — middle
- **Outlet** — bottom
- **Release** — letting the pelvic floor soften

No single move opens the whole pelvis. Sessions include modifications and notes for simple home items (a chair, and optionally a birth ball, yoga block, or light band). They include stop-if cues. A kegel routine is not the point of the release sessions. Ask your care provider which movement fits you.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000/doula-edu/](http://localhost:3000/doula-edu/).

Content checks and the static export:

```bash
npm test
npm run build
```

`npm run build` writes the site to `out/`. There is no production Node server. Pushes to `main` install dependencies, run tests, build, and deploy `out/` with GitHub Actions.

In the repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**.

No account, no backend, and no network calls for your notes. Stage, the disclaimer acknowledgment, prep-day completions, lesson and session completions, and notes stay in IndexedDB on this device.

## Screens

Routes are served under `/doula-edu/`:

- `/` Welcome — choose a stage and acknowledge the disclaimer
- `/today` Today — today's Prep card, plus the next lesson and movement session for that stage
- `/prep` Prep — the 8-week path, with room to mark earlier days and add a note
- `/learn` Learn — education modules by track
- `/learn/[id]` Lesson — read, mark complete, add a note
- `/move` Move — sessions filtered by pelvic level, plus short practices
- `/move/[id]` Session — written steps, equipment, modifications, stop-if lines, and a provider prompt
- `/progress` Progress — prep streak and days done, lesson and movement completions, and notes

You can install it as a PWA. The manifest is generated by Next.js, and a small service worker caches the shell in production.

## Safety

Lessons are practical general education. Movement sessions include “stop if …” cues and a prompt to talk with your care provider. The app does not personalize care or cite invented studies.
