# Doula

A calm, local-first web app for prenatal and postpartum education and gentle movement.

This is general wellness support. It is not medical advice, not a diagnosis, and not a treatment plan. Follow your care provider.

Hosted only on GitHub Pages, not Vercel:

https://freddyja.github.io/doula-edu/

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000/doula-edu/](http://localhost:3000/doula-edu/).

Content checks and the static export:

```bash
npm test
npm run build
```

`npm run build` writes the site to `out/`. There is no production Node server. Pushes to `main` install dependencies, run tests, build, and deploy `out/` with GitHub Actions.

In the repository, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**.

No account, no backend, and no network calls for your notes. Stage, the disclaimer acknowledgment, completions, notes, and a few interface choices (the install hint and the one-time wellness reminder) stay in IndexedDB on this device.

The interface is a phone column on every screen size, with bottom tabs for Today, Learn, Move, and Progress.

## Screens

Routes are served under `/doula-edu/`:

- `/` Welcome — first-run setup, and where you change your stage later
- `/today` Today — the next lesson and the next movement session for that stage
- `/learn` Learn — education modules by track
- `/learn/[id]` Lesson — read, mark complete, add a note
- `/move` Move — stage-appropriate guided sessions
- `/move/[id]` Session — follow along, with stop and provider cues
- `/progress` Progress — what you marked done, plus notes and the wellness reminder

You can add Doula to your home screen. Today explains how, until you dismiss that note or open the app from the home screen. The manifest is generated by Next.js, and a small service worker caches the shell in production.

## Safety

Lessons are practical general education. Movement sessions include “stop if …” cues and a prompt to talk with your care provider. The app does not personalize care or cite invented studies.
